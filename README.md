# 🤖 Chatbot PROCON

## 📌 Sobre o Projeto
O Chatbot PROCON é um aplicativo desenvolvido para auxiliar consumidores no atendimento inicial relacionado a direitos do consumidor. Ele fornece orientações, responde dúvidas frequentes e ajuda o usuário a entender os procedimentos básicos do PROCON.

## 🎯 Objetivo
Facilitar o acesso à informação e otimizar o atendimento inicial ao consumidor, oferecendo respostas rápidas e claras antes do encaminhamento para atendimento humano.

## 🚀 Funcionalidades
- Atendimento automatizado via chat  
- Respostas para dúvidas frequentes sobre direitos do consumidor  
- Orientação sobre reclamações, prazos e documentos necessários  
- Interface simples e intuitiva  

## 🛠️ Tecnologias Utilizadas
- Node.js  
- TypeScript  
- API de Inteligência Artificial  
- Front-end Web ou Mobile  

## 📦 Como Executar o Projeto
```bash
git clone https://github.com/cGuilhermec/ProconChatBoot.git
cd ProconChatBoot
npm install
npm run dev
```
